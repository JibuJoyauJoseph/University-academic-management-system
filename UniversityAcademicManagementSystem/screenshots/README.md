# Required assignment screenshots

The assignment asks for screenshots demonstrating successful table generation and relationship mappings. No screenshots are pre-filled here because they must show your own PostgreSQL database after you run the project.

After running the project against PostgreSQL, capture and save these images in this folder:

1. `01-postgresql-tables.png` — pgAdmin or another PostgreSQL client showing all generated tables under `university_academic_db`.
2. `02-table-columns-and-keys.png` — a table structure showing primary keys and foreign keys (for example `course_registrations`).
3. `03-course-lecturer-join-table.png` — the `course_lecturers` table and its two foreign keys.
4. `04-registration-relationships.png` — the `course_registrations` structure, including student/course foreign keys and registration attributes.

Do not submit screenshots from the H2 unit test as proof of PostgreSQL table generation.
